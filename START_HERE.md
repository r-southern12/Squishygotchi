# Start here

1. Unzip this folder somewhere on your computer, for example `Documents/squishy-dumpling`.
2. Install **Unity Hub** and the latest **Unity 6 LTS** editor with Android and iOS build support (iOS builds also need a Mac with Xcode).
3. Open the Claude desktop app, go to the **Code** tab, and choose this folder as the project.
4. Paste the first message below.

## First message to Claude Code

> Read CLAUDE.md and docs/spec.md, and open reference/steamer-room.html to understand the prototype. Then do Milestone 1 (project setup): create a Unity 6 URP project in this folder set up for portrait mobile, the folder structure, the data asset types for styles, item types, skins, recipes, tools, tasks and the gacha drop table, a versioned save system skeleton, and a test assembly with a first test for the gacha odds. Explain what you set up and what I need to do in Unity Hub, then stop so I can check it opens.

## After that

Work through the milestones in CLAUDE.md one at a time. After each one, open the project, play it, and tell Claude what feels wrong. Keep the design doc updated when decisions change, then refresh `docs/spec.md`.
